Why a backup existsMACK Studio · Project storage & backup
03

Cloud storage keeps files available. A backup keeps them recoverable.

Accidental deletion

A project folder is deleted by mistake.

How we recoverRestore it from the Bin within 30 days, or from the backup after that.

Minutes

Laptop lost or stolen

Nothing was stored only on that laptop.

How we recoverWe switch off its access remotely. The person signs in on another laptop and carries on.

About an hour

File overwritten

Someone saves over the latest drawing.

How we recoverOpen an earlier version from the last 30 days, or an older one from the backup.

Minutes

Hardware or ransomware

A virus scrambles files, a computer fails, or an account is misused.

How we recoverSyncing pauses automatically. We roll files back to a clean copy from before the problem.

Hours

The studio itself can be lost too, through theft or fire. Nothing important is kept only there: the main copy and the backup are online, and one of the two drives with finished projects is kept off-site.

What happens nextMACK Studio · Project storage & backup
06

What happens next. About three weeks.

1

Set up accounts

Company Google Workspace and an email address for each person.

2

Organise projects

One folder structure for every project, the same for everyone.

3

Move files

Existing projects copied in and checked. Old copies kept for 60 days.

4

Set permissions

Team, principals, office, clients: each sees only what they need.

5

Switch on backup

The independent backup starts. The two drives are filled with finished work.

6

Secure

Two-step sign-in for everyone. A lost laptop can be locked out remotely.

7

Test recovery

We delete, overwrite and "lose" files on purpose, then bring them back.

8

Go live

A 30-minute walkthrough for the team, then everyone works from the MACK drive.

What changes for the team
  • Save to the MACK drive, never only to the desktop.
  • Send clients a shared folder, not attachments or WhatsApp.
  • One person edits a drawing at a time.
  • Mistakes can be undone, so ask for help rather than redo work.
We revisit the plan when
  • MACK grows past about 10 people.
  • Online storage is three-quarters full.
  • Several people need to work on the same model at once.
  • The studio internet becomes unreliable.

MACK owns the accounts, data and infrastructure.

Every account is registered to MACK and paid by MACK. Our implementation partner has administrator access only to set up and look after the system, and that access can be removed at any time.

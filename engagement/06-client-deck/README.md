## Rebuild after edits to the source

The deck is generated by `build/build-deck.cjs` (pptxgenjs) from the website's own images in `public/media/`:

```bash
mkdir -p /tmp/deckbuild && cd /tmp/deckbuild && npm init -y >/dev/null
npm i pptxgenjs@3.12.0 sharp@0.34.5
NODE_PATH=./node_modules node <repo>/engagement/06-client-deck/build/build-deck.cjs
```

The theme colours (the website's palette) are written into the file by the pptx skill's `apply_theme.js` (set `APPLY_THEME=<path to apply_theme.js>`). Without it, PowerPoint shows the stock Office palette. Small text edits can also be made directly in PowerPoint.
